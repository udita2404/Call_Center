# Call Center Analytics Dashboard

## 📊 Overview

This Power BI project provides a detailed performance analysis of a call center using visual insights. The dashboard is designed to help decision-makers monitor key performance metrics, improve call center efficiency, and understand agent-level trends. The visuals are powered by a dataset containing over 5000 call records.

---

## 🧩 Key Features

- **Call Answer Rate**  
  Tracks the number of answered vs. unanswered calls with percentage breakdown.

- **Agent-wise Performance**  
  Measures answered/unanswered calls, average speed of answer, and average talk duration for each agent.

- **Hourly Call Trends**  
  Visualizes call volume distribution by time of day to assess peak hours.

- **Customer Rating Insights**  
  Analyzes the average customer satisfaction ratings.

- **Speed of Answer**  
  Compares individual agents on how quickly they respond to incoming calls.

## 🚀 How to Run

1. Download and install [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
2. Open the file `Call Center Analytics.pbix`.
3. Explore different pages of the dashboard to analyze KPIs and agent performance metrics.
